# 桌面端基础设施依赖

## notify 文件监听

### 用途

`notify` 为桌面端提供 Windows、macOS 和 Linux 的操作系统级文件事件监听，用于监听用户主目录中的 `AGENTS.md` 和 `~/.claude/CLAUDE.md` 变更并通知前端刷新本地快照。

### 风险

- 不同操作系统对保存、重命名和原子替换产生的事件序列可能不同。
- 文件监听事件可能重复或在文件尚未完成写入时到达，前端必须继续使用防抖和重新读取快照。
- 监听器启动失败会影响实时变更提示，但不会改变本地文件内容。

### 回滚

删除 `notify` 依赖和 `local_watcher` 模块，在 Tauri `setup` 中移除监听器注册，并恢复前端的受控状态刷新策略；同时使用 `cargo update` 或提交中的 `Cargo.lock` 回滚依赖锁定。

## Tauri tray-icon

### 用途

Tauri 的 `tray-icon` feature 提供系统托盘图标、显示窗口和退出菜单，使桌面端关闭窗口时可以继续驻留后台。

### 风险

- 托盘交互和窗口关闭语义依赖操作系统桌面环境。
- 用户点击关闭后窗口隐藏而不是退出，可能造成用户误以为应用已经结束。
- 托盘初始化失败会阻止应用启动。

### 回滚

移除 `tray-icon` feature、托盘基础设施模块和 `setup` 注册，恢复默认窗口关闭行为，并重新生成 `Cargo.lock`。

## tauri-plugin-single-instance

### 用途

Windows 平台使用单实例插件拦截重复启动，并将已有实例窗口显示和聚焦，避免多个客户端同时监听同一份本地文件。

### 风险

- 单实例锁异常可能阻止新实例启动。
- 该能力只在 Windows target 下启用，跨平台行为不一致。
- 已有实例窗口不可用时，重复启动请求只能记录错误并结束新实例。

### 回滚

移除 Windows target 下的插件依赖和 `lib.rs` 中的单实例注册，重新生成 `Cargo.lock`，保留普通多实例启动行为。

## 变更范围与权限

本次依赖只增加本地文件监听、系统托盘和 Windows 单实例能力，不新增 Tauri command，不扩大文件访问范围，不新增 capability 权限。监听器只处理规范化后匹配 `~/AGENTS.md` 或 `~/.claude/CLAUDE.md` 及其原子写入临时文件的事件路径。
